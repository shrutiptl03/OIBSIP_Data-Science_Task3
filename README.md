Task 3: Car Price Prediction
Project Overview

This project predicts the selling price of used cars based on various features such as brand, year, mileage, fuel type, and engine specifications using machine learning regression techniques.

Objective
Predict used car prices.
Understand factors affecting car valuation.
Build a regression model for price estimation.
Steps Performed
Loaded and explored the car dataset.
Handled missing values and duplicates.
Encoded categorical features.
Performed exploratory data analysis.
Selected important features.
Split data into training and testing sets.
Trained a Random Forest Regressor.
Evaluated performance using MAE, RMSE, and R² Score.
Tools Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Outcome

The model accurately predicts car prices and demonstrates how machine learning can assist buyers, sellers, and dealerships in estimating vehicle values.
